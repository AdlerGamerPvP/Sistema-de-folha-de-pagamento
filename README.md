# Sistema-de-folha-de-pagamento

Este repositorio contem codigos relacionados a um sistema de folha de pagamento, as regras da bonificação são estas: Gerentes recebem 20% da bonificação, Desenvolvedores recebem 10% e Vendedores recebem 5% mais uma comissão a parte, calculada com a quantidade de vendas no mês por valor de uma comissão.

Foi encapsulada as informações que não devem ser modificadas diretamente como nome, cpf, salario, bonificação e remuneramento total.

Os arquivos Gerente, Desenvolvedor e Vendedor herdaram o método calcularBonificacao, que também é um método abstrato junto com a classe funcionario sendo abstrata, você pode usar qualquer tipo de compilador para executar este programa como IntelliJ ou Visual Studio Code, os resultados dos meus proprio teste estara em um MD neste mesmo repositorio.
